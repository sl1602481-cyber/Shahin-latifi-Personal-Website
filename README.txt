پروژه پرتفولیوی شاهین لطیفی – Facet Glass Portfolio

اجرا در Visual Studio Code:
1) فایل ZIP را Extract کنید.
2) پوشه facet_shahin_portfolio را در Visual Studio Code باز کنید.
3) افزونه Live Server را نصب کنید.
4) روی index.html راست‌کلیک کنید و Open with Live Server را بزنید.

نکته:
- برای بارگذاری Three.js، فونت و RoomEnvironment اتصال اینترنت لازم است.
- اگر WebGL در مرورگر یا دستگاه غیرفعال باشد، نسخه HTML/CSS همچنان محتوا را نمایش می‌دهد.
- برای تغییر متن‌ها، فایل index.html را ویرایش کنید.
- برای تغییر رنگ و ظاهر، فایل style.css را ویرایش کنید.
- تعامل سه‌بعدی و حرکت شیشه‌ها در script.js قرار دارد.
- شماره تماس و آیدی تلگرام طبق اطلاعات داده‌شده درج شده‌اند.
- برای اتصال واقعی درگاه زرین‌پال، دامنه و هاست و پیاده‌سازی بک‌اند امن لازم است؛ این نسخه فقط معرفی خدمات را نمایش می‌دهد.

نسخه بهبودیافته: بخش مهارت‌ها با کارت‌های HTML5، CSS3، JavaScript، Python و SEO و آیکون‌های SVG داخلی اضافه شده است. برای آیکون‌ها نیاز به نصب کتابخانه جداگانه نیست.

به‌روزرسانی نسخه ۳: آیکون اختصاصی تلفن و تلگرام کنار اطلاعات تماس اضافه شده است. شماره با tel: و آیدی تلگرام با لینک مستقیم t.me قابل کلیک هستند.
